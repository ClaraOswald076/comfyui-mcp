<Steps>
  <Step title="Ten una instancia de ComfyUI en ejecución">
    Instala [ComfyUI Desktop](https://www.comfy.org/download) o ejecútalo
    [desde el código fuente](https://github.com/comfyanonymous/ComfyUI), e inícialo. ComfyUI MCP
    detecta automáticamente una instalación local y su puerto (8188 / 8000). Para apuntar a una
    instancia remota, consulta [Configuración](/docs/configuration).
  </Step>

  <Step title="Añade el servidor MCP a Claude Code">
    Añádelo a tu configuración de Claude Code (`~/.claude/settings.json`). `npx` descarga
    automáticamente el último paquete publicado.

    ```json ~/.claude/settings.json
    {
      "mcpServers": {
        "comfyui": {
          "command": "npx",
          "args": ["-y", "comfyui-mcp"],
          "env": {
            "CIVITAI_API_TOKEN": ""
          }
        }
      }
    }
    ```
  </Step>

  <Step title="Vuelve a conectar">
    Ejecuta `/mcp` en Claude Code (o reinícialo) para conectarte al servidor `comfyui`. Deberías
    ver que las herramientas de ComfyUI MCP quedan disponibles.
  </Step>

  <Step title="Genera algo">
    Pídeselo a tu asistente en lenguaje natural:

    > Genera una imagen de un zorro en acuarela en un bosque neblinoso.

    Por debajo, esto llama a [`generate_image`](/docs/tools/image-generation), que construye un
    flujo de trabajo txt2img, selecciona un checkpoint automáticamente, lo pone en cola y
    devuelve un `prompt_id`. La imagen terminada llega mediante la notificación de
    finalización — puedes verla con [`get_image (action:"view")`](/docs/tools/assets-images).
  </Step>
</Steps>
