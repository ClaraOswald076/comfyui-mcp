`comfyui-mcp`는 MCP 서버만이 아닙니다 — 완전한 **Claude Code
플러그인**으로 제공됩니다. 플러그인을 설치하면 Claude가 ComfyUI에 대한
전문가급, 모델별 지식을 갖게 되어 샘플러, CFG, 해상도, 모델 파일을
시행착오 없이 고릅니다.

```bash
# In Claude Code
/plugin marketplace add artokun/comfyui-mcp
/plugin install comfy
```

## 39개의 AI 스킬 — 계속 늘어납니다

스킬은 Claude가 필요할 때 불러오는 엄선된 지식 문서입니다. 각 모델
계열마다 생성 매개변수, 노드 그래프, 엄선된 모델 다운로드 URL,
실패 모드 안내가 있습니다:

| 스킬 | Claude가 배우는 것 |
|---|---|
| `flux-txt2img` | Flux.1 Dev/Schnell + Flux 2 Klein — BF16 vs FP8 함정, dual-CLIP 배선, VAE 선택 |
| `wan-t2v-video` / `wan-flf-video` | WAN 2.x 텍스트-투-비디오와 first-last-frame 워크플로우 |
| `wan-scail-replacement` | SCAIL-2 영상 속 캐릭터 교체 — reference-framing→scale 규칙, 튜닝과 합성 함정 |
| `ltxv2-video` | LTX-2.3 (그리고 LTX-2 19B) — GGUF UNet, distilled 모델, 카메라 제어 LoRA, 2단계 업스케일, kornia 수정 |
| `qwen-txt2img` / `qwen-image-edit` | Qwen-Image 생성과 지시 기반 편집 |
| `z-image-txt2img` | Z-Image Turbo 워크플로우 |
| `ideogram-ultra` | Ideogram 4 — 오픈 웨이트 텍스트-투-이미지, 영역 프롬프팅, 로고 / 포스터 / 읽히는 텍스트 |
| `ernie-image` | ERNIE-Image — 빠른 텍스트-투-이미지, 정밀한 다국어 텍스트 렌더링, 8 GB 미만 VRAM에서 실행 |
| `anima-base` | ANIMA 1.0 — ~2B 애니메/일러스트 모델, Danbooru 태그 + 자연어, 애니메 인페인팅, 6 GB 미만 VRAM |
| `anima-lora-trainer` | 커스텀 애니메 LoRA 학습 — kohya `sd-scripts` Gradio 트레이너, 6 GB 미만 VRAM |
| `ai-toolkit-trainer` | 커스텀 WAN 2.2 + Z-Image LoRA 학습 (사람 / 스타일 / 모션) — ostris AI-Toolkit, 로컬 또는 RunPod |
| `installer-packs` | 원커맨드 설치 팩을 쓰고, 만들고, 파생하기 — 그리고 새 팩을 업스트림에 기여하도록 안내 |
| `panel-node-pack-sync` | 업데이트 후 사이드바 패널 노드 팩을 오케스트레이터와 맞추기 — 버전 불일치 감지, 덮어쓰지 않고 경고만 하는 버전 핀, 결과를 디스크에서 다시 읽는 동기화 |
| `model-compatibility` | 어느 VAE/CLIP/텍스트 인코더가 어느 아키텍처와 짝인지 — 깨진 워크플로우의 1위 원인 |
| `model-registry` | 스킬이 참조하는 모든 모델의 엄선된 다운로드 URL + 대상 디렉터리 — 릴리스마다 늘어남 |
| `civitai` | 내장 `download_model` `action:"search_civitai"`로 네이티브 Civitai 발견 → 로컬 다운로드/배선/생성 루프 (키 없음, 추가 서버 없음). 공식 [Civitai MCP](https://mcp.civitai.com/mcp)는 선택적 커뮤니티 표면 애드온이며 번들에 포함되지 않음 |
| `comfyui-core` | 대기열, 히스토리, API 의미 |
| `comfyui-node-registry` | Comfy Registry에 커스텀 노드 팩 작성 + 게시 |
| `comfyui-frontend-extensions` | v1/v2 프론트엔드 확장 작성 (사이드바 탭, 위젯) |
| `rgthree` | rgthree-comfy 설정 — Fast Groups Bypasser/Muter 그룹 토글 (`/object_info`에 없는 프론트엔드 전용 노드, 위젯이 아니라 노드 PROPERTIES로 설정), Power Lora Loader 스택, Context 버스 |
| `director` | 비디오 파이프라인용 멀티샷 장면 연출 |
| `prompt-engineering` | 아키텍처별 프롬프팅 (자연어 vs 태그) |
| `troubleshooting` | OOM, 누락된 노드, 버전 드리프트 — 진단 트리 |
| `comfyui-launch-flags` | VRAM/attention/cache/perf 실행 플래그 매트릭스 — `--reserve-vram`, `--novram`+`--cache-none`, `--use-sage-attention` vs `--use-pytorch-cross-attention` (Z-Image), 그리고 Blackwell/RTX 5000 가속 스택 메모 |

새 스킬은 릴리스마다 들어옵니다 — 인기 레지스트리 팩에서 내장
`list_packs` 도구 (`action: "generate_skill"`)로 생성한 뒤 사람이 다듬습니다.

**아무것도 연결하기 전에 지식을 시험해 보세요** — 모든 스킬은 평범한
마크다운 파일이며 그 자체로 유용합니다. 가장 폭넓게 적용되는 것은
[`prompt-engineering`](https://github.com/artokun/comfyui-mcp/blob/main/plugin/skills/prompt-engineering/SKILL.md)
입니다 — CLIP의 77토큰 한도와 `BREAK` 청킹, 가중치 문법, 아키텍처별
전략 (왜 Flux는 자연어를 원하고 네거티브 프롬프트가 없는지, SD1.5는
태그를 원하는지). 브라우저에서 읽거나, 어떤 에이전트의 컨텍스트에도
시스템 프롬프트로 붙여넣으세요 — ComfyUI, MCP, 설치가 필요 없습니다. 전체
플러그인을 연결하면 에이전트가 같은 파일을 자동으로 불러옵니다 (`list_packs`의
`action: "skill_read"`).

### 내장 Civitai 검색

`download_model` `action:"search_civitai"`는 Civitai를 네이티브로 검색합니다 (공개 REST API, 키 없음,
추가 서버 없음): 키워드 + `types` + `base_models` 필터 ("**Flux** LoRA"),
기본값은 SFW만, 모든 히트가 `action:"download_civitai"`가 바로 받는
`model_version_id`와 프롬프트용 모델의 **트리거 워드**를 반환합니다.
일급 도구이므로 **모든 백엔드**에서 동작하며, 컴팩트 라우터 뒤의 작은
로컬 모델도 포함됩니다. `civitai` 스킬이 발견 → 다운로드 → 생성
인계를 가르칩니다.

**선택적 API 키.** 검색에는 필요 없습니다. `CIVITAI_API_TOKEN`이
게이트/얼리액세스 다운로드와 게이트된 검색 결과를 엽니다 — 변수 하나가
검색과 다운로드를 모두 담당합니다.

**선택: 공식 Civitai MCP.** 검색→설치를 넘는 커뮤니티 표면
(예제 이미지 + 생성 매개변수 둘러보기, 게시, 컬렉션)을 위해
Civitai의 [공식 원격 서버](https://mcp.civitai.com/mcp)를 짝지으세요
— 더 이상 자동 번들되지 않으니, 한 번 추가하세요:

```bash
claude mcp add --transport http civitai https://mcp.civitai.com/mcp \
  --header "Authorization: Bearer YOUR_CIVITAI_API_KEY"
```

## 슬래시 명령어 11개

`/comfy:gen` (프롬프트로 생성), `/comfy:debug` (실패한 워크플로우
진단), `/comfy:install` (노드 팩 설치), `/comfy:viz` (워크플로우 →
Mermaid), `/comfy:batch`, `/comfy:compare`, `/comfy:convert`, `/comfy:gallery`,
`/comfy:recipe`, `/comfy:director`, `/comfy:node-skill`.

## 자율 에이전트 4개

- **comfy-explorer** — 노드 팩 소스를 깊게 파고들어 문서화
- **comfy-researcher** — 문제 진술 → 순위가 매겨진 팩 추천
- **comfy-debugger** — 히스토리 + 로그로 실패한 워크플로우의 근본 원인
- **comfy-optimizer** — 주어진 GPU에 대한 VRAM과 속도 튜닝

## 사이드바 패널 — API 키 없음

<Note>
  사이드바 패널은 자체 팩으로 제공되며, **Comfy Registry와
  ComfyUI-Manager에 `comfyui-agent-panel`로** 올라 있습니다 — 거기서 검색하고
  Nightly가 아니라 **Latest**를 고르세요. 전체 가이드: [사이드바 패널](/docs/ko/panel).
</Note>

[comfyui-mcp-panel](https://github.com/artokun/comfyui-mcp-panel) 사이드바는
**Claude 구독**으로 자율 에이전트를 실행합니다 (토큰당 API 과금 없음).
팩을 설치하고 에이전트 탭을 연 뒤 **연결**을 클릭하세요 — 필요할 때
[패널 오케스트레이터](/docs/ko/configuration)를 시작합니다. 이미지나 워크플로우,
변경을 요청하면 사용자의 ComfyUI를 대상으로 작업합니다.

## 훅

세 훅이 생성 세션을 단단히 유지합니다: 워크플로우를 대기열에 넣기 전의
**VRAM 사전 점검**, **작업 완료 알림**, 파괴적 작업 전의
**저장 경고**.
