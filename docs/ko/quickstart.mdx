---

<Steps>
  <Step title="ComfyUI 인스턴스 실행하기">
    [ComfyUI Desktop](https://www.comfy.org/download)을 설치하거나
    [소스에서 직접 실행](https://github.com/comfyanonymous/ComfyUI)한 다음 구동하세요. ComfyUI MCP는
    로컬 설치와 포트(8188 / 8000)를 자동으로 감지합니다. 원격 인스턴스를 대상으로 하려면
    [설정](/docs/configuration) 문서를 참고하세요.
  </Step>

  <Step title="Claude Code에 MCP 서버 추가하기">
    Claude Code 설정(`~/.claude/settings.json`)에 추가하세요. `npx`가 최신 게시된 패키지를
    자동으로 가져옵니다.

    ```json ~/.claude/settings.json
    {
      "mcpServers": {
        "comfyui": {
          "command": "npx",
          "args": ["-y", "comfyui-mcp"],
          "env": {
            "CIVITAI_API_TOKEN": ""
          }
        }
      }
    }
    ```
  </Step>

  <Step title="다시 연결하기">
    Claude Code에서 `/mcp`를 실행하거나 Claude Code를 재시작해서 `comfyui` 서버에 연결하세요.
    ComfyUI MCP 도구들을 사용할 수 있게 됩니다.
  </Step>

  <Step title="직접 생성해 보기">
    자연어로 어시스턴트에게 요청해 보세요:

    > 안개가 낀 숲속에 있는 수채화풍 여우 이미지를 생성해 줘.

    내부적으로는 [`generate_image`](/docs/tools/image-generation)를 호출해 txt2img 워크플로우를
    구성하고, 체크포인트를 자동으로 선택한 뒤 대기열에 추가하고 `prompt_id`를 반환합니다.
    완성된 이미지는 완료 알림을 통해 도착합니다 — [`get_image (action:"view")`](/docs/tools/assets-images)로
    확인하세요.
  </Step>
</Steps>
