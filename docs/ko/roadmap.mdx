## 이 페이지가 다루는 것

**저장소 하나가 아니라 프로젝트 전체입니다.** comfyui-mcp는 따로 출시되고
독립적으로 버전되는 여러 조각입니다:

| 조각 | 저장소 | 무엇인가 |
|---|---|---|
| **MCP 서버 + 플러그인** | [`comfyui-mcp`](https://github.com/artokun/comfyui-mcp) | 도구와 오케스트레이터 — 컨트롤 플레인 |
| **패널** | [`comfyui-mcp-panel`](https://github.com/artokun/comfyui-mcp-panel) | ComfyUI 안의 에이전트 사이드바 |
| **모바일 앱** | [`comfyui-mcp-mobile`](https://github.com/artokun/comfyui-mcp-mobile) | 채팅, 대기열, LoRA, 데스크톱 탭 미러링 |
| **릴레이** | [`comfyui-mcp-relay`](https://github.com/artokun/comfyui-mcp-relay) | 안정적인 `wss://` 원격 브리지를 위한 Cloudflare Worker |

아래 항목은 중요한 곳에서 조각으로 표시됩니다. 네 곳에 착지하더라도
하나의 제품으로 계획됩니다.

<Warning>
  [여기까지 온 길](#여기까지-온-길)의 버전 번호는 **MCP
  서버의 것**입니다. 패널과 모바일 앱은 각자의, 관련 없는 버전
  줄을 가집니다 — 패널 0.9.x는 서버 v0.44보다 "뒤처진" 것이 아닙니다. 비교하지 마세요.
</Warning>

## 읽는 방법

**이 페이지에는 날짜가 없고, 그것은 의도적입니다.**

이 프로젝트는 빠르게 출시하고 자주 순서를 바꿉니다 — RunPod 아크는
단 일주일 만에 줄을 건너뛰었습니다. 분기가 적힌 로드맵은 며칠 안에 틀리며,
틀린 날짜는 날짜 없음보다 나쁩니다: 아무도 하지 않은 약속을 계획으로 바꿉니다.

그래서 이 페이지는 **순서를 약속하지, 시점을 약속하지 않습니다**. "다음"은 줄에서
다음이지, 다음 달이 아닙니다. 여기 있는 것이 중요하다면
[Discord](https://discord.gg/cW9arBhzCu)에서 말해 주세요 — 사람들이 실제로 매일 하는 일이
요청의 크기보다 훨씬 더 믿을 수 있게 이 목록을 끌어올립니다.

가장 유용한 섹션은 아마 마지막일 것입니다. **[계획에 없음](#계획에-없음)**은
우리가 *반대*로 결정한 것과 이유를 말하므로, 기다림을 멈출 수 있습니다.

여기 있는 모든 것은 오늘 동작하며 문서가 다룹니다.

| 영역 | 얻는 것 |
|---|---|

| **직접 모델을 가져오기** | Claude, ChatGPT/Codex, Gemini, Antigravity, Grok, Kimi, GLM, Ollama, LM Studio, llama.cpp, OpenRouter, 또는 커스텀 엔드포인트 — 선택기 하나, 오케스트레이터 하나. [백엔드](/docs/ko/backends)를 참고하세요. |
| **로컬 모델** | Ollama / LM Studio / llama.cpp를 통한 완전 로컬 동작, 작은 모델 포함. [로컬 LLM](/docs/ko/local-llms)을 참고하세요. |
| **워크플로우 작성** | 자연어로 워크플로우를 만들고, 패치하고, 슬라이스하고, 검증하고, 잠급니다. 이미지 메타데이터에서 가져옵니다. |
| **모델과 커스텀 노드** | 노드 팩을 검색, 설치, 수리합니다. 모델을 찾아 다운로드합니다 — 워크플로우에 빠진 모델과 VRAM에 맞는 양자화도 알아냅니다. |
| **Civitai 브라우저** | 패널 안에서 이미지, 동영상, 모델을 둘러보고, 베이스 모델과 크리에이터로 필터하고, 워크플로우를 캔버스에 바로 끌어옵니다. |
| **모바일 앱** | 에이전트와 채팅하고, 대기열을 보고, LoRA를 둘러보고, 데스크톱 탭을 미러해 휴대폰에서 장비를 제어합니다. [모바일](/docs/ko/mobile)을 참고하세요. |
| **앱 (마이크로앱)** | 워크플로우를 실제 폼이 있는 원클릭 앱으로 바꿉니다: 패널에서 변환하고 게시하고, 로컬이나 파드에서 실행하고, 공개 레지스트리에서 다른 사람의 앱을 설치하고 — 같은 앱을 휴대폰의 앱 탭이나 `apps_*` 도구를 통한 에이전트에서도 실행합니다. [앱](/docs/ko/apps)을 참고하세요. |
| **원격과 클라우드** | 패널을 원격 ComfyUI, 셀프호스팅 릴레이, 또는 Comfy Cloud로 향하게 합니다. [원격 커넥터](/docs/ko/remote-connector)를 참고하세요. |
| **RunPod 파드** | 패널에서 RunPod 파드를 만들고, 연결하고, 정지합니다. 과금에 안전한 기본값과 정직한 호스트 표시가 있습니다. |
| **LoRA 학습 (로컬)** | FLUX.1-dev 위의 캐릭터 LoRA. 에이전트가 GPU Docker 컨테이너에서 `train_*` 도구로 구동합니다 — 데이터셋 인, `models/loras/`의 `.safetensors` 아웃. |

## 지금 만드는 중

활발히 진행 중입니다. 다음에 움직일 가능성이 가장 큰 것들입니다.

| 항목 | 현재 위치 |
|---|---|
| **RunPod 파드에서의 LoRA 학습** | 트랜스포트가 착지했습니다. 후속 작업은 유휴 정지 범위와 Docker 없는 머신을 위한 도커리스 네이티브 경로에서 이어집니다. |
| **캐릭터 LoRA를 넘는 학습** | 스타일, 슬라이더, 편집 플로우, FLUX.1-dev를 넘는 베이스 모델. 설정 계층은 넓히도록 만들어졌고, 플로우는 아직 쓰이지 않았습니다. |

## 검토 중

원하지만, 노력이 아니라 설계 질문에 막혀 있습니다. 약속 없음.

### 다중 사용자 세션

다른 사람이 *당신의* 세션에 연결해 *당신의* 머신을 구동하게 하기 — 깨진
워크플로우를 짝 디버깅하거나, 공유 스튜디오 장비.

막힌 지점을 정확히 말할 가치가 있습니다. 뻔한 것이 아니기 때문입니다:
**트랜스포트는 이미 있습니다.** 페어링, 소켓 팬아웃, 세션별 인증은
모두 휴대폰-투-데스크톱 미러링을 위해 만들어졌고, 그것은 같은 배관입니다.

빠진 것은 **신뢰 모델**입니다. 누가 운전할 수 있는가? 캔버스, 히스토리,
파일시스템 중 무엇을 볼 수 있는가? 실행 도중에 어떻게 접근을 회수하는가?
그중 어느 것도 만들기 전에 그 질문에 답해야 합니다 —
다른 사람의 GPU 위에 반만 설계된 답을 출시하는 것이 사람을 다치게 하는 방법입니다.

## 계획에 없음

반대한 결정과 이유, 그래서 아무도 기다리지 않습니다. 영구적이지 않습니다 —
좋은 논거는 어느 것이든 다시 엽니다 — 하지만 여기 있는 것은 대기열에 없습니다.

### 날짜와 버전 번호가 붙은 마일스톤

[이 페이지의 맨 위](#읽는-방법)를 참고하세요. 순서를, 시점을 아닙니다.

### 음성 전용 제어 (스마트 글래스, 헤드셋)

글래스에서 음성으로 데스크톱 에이전트를 구동하는 이야기는 자주 나오며, 배관은
대부분 미러링 트랜스포트를 재사용할 것입니다.

대기열에 올리지 않은 이유는 음성 전용 표면에는 **캔버스가 없다**는 것입니다.
흘끗 볼 미리보기가 없고, 두 개가 로드되어 있을 때 *"다른 LoRA를 써"*를
해결할 방법이 없으며, 에이전트가 그래프에 잘못된 일을 했을 때 보이는
되돌리기가 없습니다. 그것이 실제 문제이고, 마이크를 더한다고 그중
어느 것도 풀리지 않습니다. 답이 있기 전까지, 이것은 의지하기 불쾌한
데모로 출시될 것입니다.

### 스마트워치

위의 모든 것이 적용되며, 더 작은 화면과 더 빠듯한 전력 예산입니다. 아직
아무도 휴대폰이 이미 하는 것보다 잘 하는 일을 설명하지 못했습니다.

### 대신 ComfyUI를 실행해 주는 호스팅 서비스

이 프로젝트는 **로컬 우선 컨트롤 플레인**입니다. 사용자의 ComfyUI에 연결합니다 —
머신, 원격 박스, 파드, 또는 Comfy Cloud — 그리고 파일이나 프롬프트를
원하지 않습니다. 사용자를 대신해 추론을 실행하는 것은 다른 신뢰 모델을 가진
다른 제품이며, 이것이 아닙니다.

## 여기까지 온 길

다음 항목이 앉는 자리를 위한 맥락으로서, 지금까지의 아크입니다. 의도적으로
거칠습니다 — 특정 릴리스에서 무엇이 바뀌었는지는
[변경 로그](/docs/changelog)를 참고하세요.

<Note>
  공개 릴리스는 **v0.2.0**에서 시작합니다. v0.0.1이나 v0.1.x는 없습니다 — 처음
  두 주의 작업이 패키지가 게시되기 전에 바로 `main`에 착지했고,
  **2026-02-15**의 최초 커밋에서 시작했습니다.
</Note>

표시된 릴리스는 **MCP 서버의 것**입니다 — 패널과 모바일 앱은 따로
버전되며, 아래 시대는 프로젝트 전체를 설명합니다.

| 시대 | 서버 릴리스 | 무엇이었는가 |
|---|---|---|
| **MCP 서버**<br/>2026년 2월 | v0.2 – v0.3 | 원래 아이디어: 에이전트로 ComfyUI를 구동하기. 이미지 생성, 워크플로우 분석, UI→API 워크플로우 변환기, 계층적 시각화, 모델 스킬, 그리고 블로킹 실행에서 백그라운드 진행과 프로세스 제어가 있는 논블로킹 대기열로의 전환. |
| **조용한 구간**<br/>2026년 3월 – 4월 | v0.3.x | 두 달에 기능 커밋 세 개. HTTP 위의 원격 ComfyUI, 변환기의 서브그래프/컴포넌트 확장, HTTPS/WSS 지원. 헤드라인이 아니라 기초 작업. |
| **환경과 수명 주기**<br/>2026년 5월 | v0.4 – v0.8 | 실제 설치에서 살아남게 만들기: CI가 있는 커스텀 노드 검증/스캐폴드, git ref에 고정된 설치, 게이트/비공개 모델 인증, 선언적 환경 매니페스트, 클라우드 스토리지 제공자, 서버 측 이미지 변환, 캐시된 노드 스킬 발견. 임베디드 패널이 이 구간의 끝에서 설계되었습니다. |
| **패널 시대**<br/>2026년 6월 | v0.9 – v0.22 | 볼륨으로 가장 큰 달 (~102개 기능 커밋). 에이전트가 캔버스 옆 *ComfyUI 안*으로 옮겨 왔고, 여러 제공자를 얻었으며, 어디서든 실행할 인프라가 자랐습니다: 원클릭 설치 팩, RunPod 이미지, 옵트인 릴레이가 있는 보안 `wss://` 브리지, 실시간 추론 가시성. |
| **도달과 깊이**<br/>2026년 7월 | v0.23 – v0.44 | 한 번에 두 방향. **도달:** 모바일 앱, 데스크톱 탭 미러링, Civitai 브라우저, 더 많은 제공자 (Antigravity, GLM, Kimi), 작은 로컬 모델이 도구를 구동할 수 있게 하는 컴팩트 도구 모드. **깊이:** LLM 아레나, 과금에 안전한 기본값이 있는 퍼스트파티 RunPod 파드, LoRA 학습, VRAM을 고려하는 누락 모델 해석. |

그 표가 말하지 않는 두 가지. 속도는 일부러 고르지 않습니다 — 봄의
두 달 소강, 그다음 6월과 7월에 걸쳐 ~180개 기능 커밋.
그리고 순서는 미리 고정된 적이 없습니다: RunPod와 학습이 둘 다
줄을 건너뛴 것은, 명목상 다음보다 더 중요해졌기 때문입니다. 이것이
이 페이지에 날짜가 없는 주된 이유입니다.

## 빠진 것이 있나요?

목록에 없는 것을 기다리고 있거나, "계획에 없음" 판단 중 하나가
실제로 일하는 방식에 틀려 보인다면,
[GitHub](https://github.com/artokun/comfyui-mcp/issues)에 이슈를 열거나

훨씬 더 유용합니다 — 이 페이지의 여러 항목이 그렇게 정렬된 것은
누군가가 자기 하루를 설명했기 때문이지, 가장 크게 요청했기 때문이 아닙니다.
