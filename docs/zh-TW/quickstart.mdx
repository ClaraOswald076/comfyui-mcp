---

<Steps>
  <Step title="先讓一個 ComfyUI 執行個體跑起來">
    安裝 [ComfyUI Desktop](https://www.comfy.org/download)，或是
    [從原始碼執行](https://github.com/comfyanonymous/ComfyUI)，然後把它啟動。ComfyUI MCP
    會自動偵測本機的安裝與它的連接埠（8188 / 8000）。要指向遠端的執行個體，
    請看[設定](/docs/configuration)。
  </Step>

  <Step title="把 MCP 伺服器加進 Claude Code">
    把它加進你的 Claude Code 設定（`~/.claude/settings.json`）。`npx` 會自動抓取最新發布的
    套件。

    ```json ~/.claude/settings.json
    {
      "mcpServers": {
        "comfyui": {
          "command": "npx",
          "args": ["-y", "comfyui-mcp"],
          "env": {
            "CIVITAI_API_TOKEN": ""
          }
        }
      }
    }
    ```
  </Step>

  <Step title="重新連線">
    在 Claude Code 裡執行 `/mcp`（或重新啟動它）以連線到 `comfyui` 伺服器。你應該會看到
    ComfyUI MCP 的工具變成可以使用。
  </Step>

  <Step title="來生成點東西">
    用自然語言對你的助理提出要求：

    > 生成一張水彩風格的狐狸圖片，背景是霧氣瀰漫的森林。

    在底層，這會呼叫 [`generate_image`](/docs/tools/image-generation)：它會建立一個 txt2img
    工作流程、自動挑選主模型、把它排入佇列，並回傳一個 `prompt_id`。完成的圖片會透過完成
    通知送達 —— 用 [`get_image (action:"view")`](/docs/tools/assets-images) 檢視。
  </Step>
</Steps>
