---
title: "快速开始"
description: "把 ComfyUI MCP 添加到 Claude Code，生成你的第一张图片。"
icon: "rocket"
---

<Steps>
  <Step title="准备一个正在运行的 ComfyUI 实例">
    安装 [ComfyUI Desktop](https://www.comfy.org/download)，或者
    [从源码运行](https://github.com/comfyanonymous/ComfyUI)，然后启动它。ComfyUI MCP
    会自动检测本地安装及其端口（8188 / 8000）。要连接远程实例，请参见
    [配置](/docs/configuration)。
  </Step>

  <Step title="把 MCP 服务器添加到 Claude Code">
    把它添加到你的 Claude Code 配置（`~/.claude/settings.json`）中。`npx` 会自动获取最新
    发布的软件包。

    ```json ~/.claude/settings.json
    {
      "mcpServers": {
        "comfyui": {
          "command": "npx",
          "args": ["-y", "comfyui-mcp"],
          "env": {
            "CIVITAI_API_TOKEN": ""
          }
        }
      }
    }
    ```
  </Step>

  <Step title="重新连接">
    在 Claude Code 中运行 `/mcp`（或重启 Claude Code）以连接到 `comfyui` 服务器。你应该会
    看到 ComfyUI MCP 的工具变为可用。
  </Step>

  <Step title="生成点什么">
    用自然语言向你的助手提问：

    > 生成一张雾气森林中水彩风格狐狸的图片。

    在底层，这会调用 [`generate_image`](/docs/tools/image-generation)：它构建一个 txt2img
    工作流，自动选择大模型，把它加入队列，并返回一个 `prompt_id`。生成完成的图片会通过
    完成通知送达 —— 用 [`get_image (action:"view")`](/docs/tools/assets-images) 查看。
  </Step>
</Steps>
