## 本页覆盖什么

**整个项目，不是某一个仓库。** comfyui-mcp 是几块分开出货、独立版本的东西：

| 部分 | 仓库 | 它是什么 |
|---|---|---|
| **MCP 服务器 + 插件** | [`comfyui-mcp`](https://github.com/artokun/comfyui-mcp) | 工具和编排器 —— 控制平面 |
| **面板** | [`comfyui-mcp-panel`](https://github.com/artokun/comfyui-mcp-panel) | ComfyUI 里的智能体侧边栏 |
| **移动端 App** | [`comfyui-mcp-mobile`](https://github.com/artokun/comfyui-mcp-mobile) | 聊天、队列、LoRA 以及桌面标签页镜像 |
| **中继** | [`comfyui-mcp-relay`](https://github.com/artokun/comfyui-mcp-relay) | 给稳定 `wss://` 远程桥接用的 Cloudflare Worker |

下面的条目在有必要时按部分标注。即便落地在四个地方，规划时仍当作一个产品。

<Warning>
  [怎么走到今天](#怎么走到今天) 里的版本号是 **MCP 服务器的**。面板和移动端 App
  走各自无关的版本线 —— 面板 0.9.x 并不是「落后于」服务器 v0.44。别拿它们比。
</Warning>

## 怎么读

**本页没有日期，这是故意的。**

这个项目出货很快，也经常重排 —— RunPod 这条线一周之内就插到了队列前面。一份标了季度
的路线图几天就会错，而错的日期比没有日期更糟：它把计划变成了没人做过的承诺。

所以本页承诺的是**顺序，不是时机**。「接下来」是排队下一项，不是下个月。如果这里有
对你重要的东西，请到 [Discord](https://discord.gg/cW9arBhzCu) 说 —— 人们每天真正在
做的事，比请求的嗓门更能把条目往上推。

最有用的一节大概是最后一节。**[不计划做](#不计划做)** 写明我们决定*反对*什么以及
为什么，这样你就不用再等它。

## 已发布

这里的每一项今天都能用，并且有文档覆盖。

| 领域 | 你得到什么 |
|---|---|
| **ComfyUI 里的智能体** | 面板把智能体放在画布旁边 —— 它读节点图、编辑节点、跑工作流，并解释失败。见 [面板](/docs/zh/panel)。 |
| **带上你自己的模型** | Claude、ChatGPT/Codex、Gemini、Antigravity、Grok、Kimi、GLM、Ollama、LM Studio、llama.cpp、OpenRouter，或自定义端点 —— 一个选择器，一个编排器。见 [后端](/docs/zh/backends)。 |
| **本地模型** | 通过 Ollama / LM Studio / llama.cpp 完全本地运行，包括小型模型。见 [本地 LLM](/docs/zh/local-llms)。 |
| **工作流编写** | 用自然语言构建、打补丁、切片、校验并锁定工作流；从图片元数据导入。 |
| **模型与自定义节点** | 搜索、安装和修复节点包；查找并下载模型 —— 包括算出工作流缺哪些模型、哪种量化适合你的显存。 |
| **Civitai 浏览器** | 在面板里浏览图片、视频和模型，按基础模型和创作者筛选，并把工作流直接拉到画布上。 |
| **移动端 App** | 和智能体聊天、看队列、浏览 LoRA，并镜像桌面标签页，用手机驱动你的机器。见 [移动端](/docs/zh/mobile)。 |
| **应用（微应用）** | 把工作流变成带真实表单的一键应用：在面板里转换并发布，在本地或实例上跑，从公共注册表安装别人的应用 —— 同一套应用也能从手机的 Apps 标签页或通过 `apps_*` 工具由智能体运行。见 [应用](/docs/zh/apps)。 |
| **远程与云端** | 把面板指向远程 ComfyUI、自建中继或 Comfy Cloud。见 [远程连接器](/docs/zh/remote-connector)。 |
| **RunPod 实例** | 从面板创建、连接并停止 RunPod 实例，带计费安全的默认值和诚实的主机指示。 |
| **LoRA 训练（本地）** | 在 FLUX.1-dev 上练角色 LoRA，由智能体通过 GPU Docker 容器里的 `train_*` 工具驱动 —— 数据集进，`.safetensors` 从 `models/loras/` 出。 |

## 考虑中

想做，但卡在设计问题上，不是卡在工作量上。没有承诺。

### 多用户会话

让别人连上*你的*会话、驱动*你的*机器 —— 结对调试一条坏掉的工作流，或共用一台工作室
机器。

值得把卡点说清楚，因为它不是那个显而易见的：
**传输已经存在。** 配对、套接字扇出和按会话的认证，都是为手机到桌面镜像建的，那是同一套
管道。

缺的是**信任模型**。谁被允许驱动？他们能看到你画布、历史、文件系统的哪些部分？怎么在
跑到一半时撤销某人的访问？这些问题需要先答完再动手 —— 在别人的 GPU 上发布一份半成品
答案，是伤人的方式。

## 不计划做

已经决定不做，并写明理由，这样没人会空等。不是永久的 —— 好的论证会重开其中任何一项
—— 但这里没有排队的东西。

### 日期和带版本号的里程碑

见 [本页开头](#怎么读)。顺序，不是时机。

### 纯语音控制（智能眼镜、头戴设备）

用眼镜语音驱动桌面智能体经常被提起，管道也大体能复用镜像传输。

没排队的原因是：纯语音界面**没有画布**。没有可以扫一眼的预览，没法在加载了两个 LoRA
时消解「用另一个 LoRA」，智能体把节点图做错时也没有可见的撤销。这些才是真正的问题，
加一个麦克风解决不了其中任何一个。在有答案之前，这会作为一份不好依赖的演示发出去。

### 智能手表

上面那些全部适用，再叠上更小的屏幕和更紧的电量预算。还没有人描述过它比手机已经在做的
事情做得更好的一份工作。

### 替你运行 ComfyUI 的托管服务

本项目是**本地优先的控制平面**。它连到你的 ComfyUI —— 在你的机器、远程盒子、实例或
Comfy Cloud 上 —— 并且不想要你的文件或提示。替你跑推理是另一种产品、另一套信任模型，
不是这个。

## 怎么走到今天

到目前为止的弧线，给下一批条目提供上下文。故意写得很粗 —— 某次发布具体改了什么，见
[更新日志](/docs/changelog)。

<Note>
  公开发布从 **v0.2.0** 开始。没有 v0.0.1 或 v0.1.x —— 头两周的工作直接落在 `main`
  上，包发布之前就开始了，从 **2026-02-15** 的初始提交算起。
</Note>

所示发布是 **MCP 服务器的** —— 面板和移动端 App 分开版本，下面的时代描述的是整个
项目。

| 时代 | 服务器发布 | 它在做什么 |
|---|---|---|
| **MCP 服务器**<br/>2026 年 2 月 | v0.2 – v0.3 | 最初的想法：用智能体驱动 ComfyUI。图像生成、工作流分析、UI→API 工作流转换器、分层可视化、模型技能，以及从阻塞运行转到带后台进度和进程控制的非阻塞队列。 |
| **安静的一段**<br/>2026 年 3 – 4 月 | v0.3.x | 两个月里三个功能提交。通过 HTTP 的远程 ComfyUI、转换器里的子图 / 组件展开、HTTPS/WSS 支持。地基，不是头条。 |
| **环境与生命周期**<br/>2026 年 5 月 | v0.4 – v0.8 | 让它在真实安装里活下来：带 CI 的自定义节点校验 / 脚手架、钉到 git ref 的安装、门禁和私有模型的认证、声明式环境清单、云存储提供商、服务端图像转换，以及缓存的节点技能发现。内嵌面板在这段末尾设计出来。 |
| **面板时代**<br/>2026 年 6 月 | v0.9 – v0.22 | 按体量最大的一个月（约 102 个功能提交）。智能体*走进* ComfyUI、待在画布旁边，拿到多个服务商，并长出能在任何地方跑的基础设施：一键安装包、RunPod 镜像、带可选中继的安全 `wss://` 桥接，以及实时推理可见性。 |
| **触达与深度**<br/>2026 年 7 月 | v0.23 – v0.44 | 两个方向同时推进。**触达：** 移动端 App、桌面标签页镜像、Civitai 浏览器、更多服务商（Antigravity、GLM、Kimi），以及让小型本地模型能驱动工具的紧凑工具模式。**深度：** LLM 竞技场、带计费安全默认值的官方 RunPod 实例、LoRA 训练，以及会考虑你显存的缺失模型解析。 |

那张表不会告诉你两件事。节奏故意不均匀 —— 春天两个月的静默，然后六七月大约 180 个
功能提交。排序也从来没有提前钉死：RunPod 和训练都插队了，因为它们后来比名义上下一项
更重要。这也是本页不带日期的主要原因。
